# Legacy Code

## Origine du projet

Il y a des programmes qu'on ferme.

D'autres qu'on désinstalle.

Et puis il y a ceux qu'on croit avoir supprimés.

Pendant douze ans, j'étais persuadé d'avoir fait exactement ça.

```text id="f6ds32"
elle.exe
Status: stopped
CPU: 0%
Memory: negligible
Last activity: 12 years ago
```

Tout allait bien.

Puis un jour, presque par hasard, j'ai retrouvé quelques lignes.

Un vieux fichier.

Rien de bien dangereux.

Mon cerveau a donc pris la décision la plus raisonnable possible :

**l'exécuter.**

```text id="m0ka71"
$ ./elle.exe

Loading legacy dependencies...
Restoring cached memories...
Mounting /dev/past...

WARNING:
Process was never properly terminated.
```

Et là, bordel.

```text id="x4jv29"
╔══════════════════════════════════════╗
║            SYSTEM ALERT              ║
╠══════════════════════════════════════╣
║ CPU ............... 100%             ║
║ RAM ............... 100%             ║
║ EMOTIONS .......... 100%             ║
║ REASON ............ UNKNOWN          ║
╚══════════════════════════════════════╝

WARNING: System stability compromised.
```

J'ai commencé à écrire pour remettre un peu d'ordre dans tout ça.

Quelques pages, normalement.

Un petit projet tranquille.

Ça a évidemment dégénéré.

J'ai appelé ça **Legacy Code**.

Je n'ai toujours pas trouvé la commande pour tuer le processus.

Alors j'ai décidé de documenter le code.
